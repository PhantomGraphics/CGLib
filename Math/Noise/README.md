# CPU noise and fractal composition

`Phantom::Math::Noise::PerlinNoise(seed)` provides checked `sample2D(x,y)` and
`sample3D(x,y,z)` returning `std::optional<float>`. The immutable permutation
is generated by SplitMix32 and can be shared between threads. The 2D algorithm
preserves the generatorVersion 1 terrain results. It repeats every 256 units
on each axis; output is signed and is not clamped to [-1,1].

`evaluateFractal(sampleAtFrequency, settings)` combines samples with normalized
amplitude weights. Modes are None (0), FBm (1), Turbulence (2, absolute value),
Ridged (3, squared max(0,1-abs(value))). Defaults: five octaves, lacunarity 2,
gain 0.5. Valid settings: 1..12 octaves, finite lacunarity >1, gain in [0,1].
Invalid coordinates/settings and failed octave samples return nullopt.

GeometryNode Noise2D/Noise3D expose these operations as point Float fields.
Noise2D samples XZ; unlinked Position uses mesh vertices. Coordinates are
Position * Scale + Offset. Seed combines graph and node seeds with randomHash.
Use Value -> CombineXYZField.Y -> SetPosition.Offset for height displacement.
Studio's catalog, parameter editor, history and persistence use these nodes
through the existing generic graph implementation. FractalMode is an integer
with the mapping above. See the geometry_noise.json Studio scenario.
